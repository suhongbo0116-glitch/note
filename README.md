# note

关于GitHub的操作

一、建立仓库

二、克隆仓库至本地：[bash]git clone xxxxxxxxxxxxx（由仓库SSH生成）

三、上传笔记

1、打开主文件：[bash]cd XXXX/（XXXX为仓库名称）

２、新建分支：（１）[bash]git branch xxxx（分支名称）

                   （2）新建文件夹xxxx

                   （3）[bash]git switch xxxx

                   （4）新建txt，并将笔记上传至txt，保存后修改.txt为.md

  3、上传分支：（1）[bash]git add *

                        （2）[bash]git commit -m "描述"

                        （3）[bash]git push origin xxxx

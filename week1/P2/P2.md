**总结（漏洞利用链）**：

1. v1 是 short 类型，最大值 32767

2. 每输入一个正数（比如 1），v1 加 1

3. 输入 32767 次后，v1 = 32767（short 最大值）

4. 第 32768 次输入正数：32767 + 1 = 32768，short 装不下，整数溢出回绕成 -32768

5. -32768 < 0 条件成立 → 触发 system("cat flag")
